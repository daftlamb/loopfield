# 钢琴示例工程

这两个 JSON 保存已经完成的切片、条件触发与游走预设，不包含原始音频。

使用前，复制 JSON 到掌机 `Apps/Loopfield/projects/`，并自行提供对应 WAV 到 `Apps/Loopfield/samples/`：

- Piano Chords Downsample E.wav
- Piano Chords Moody 80 Bpm C.wav
- Piano Chords Pop 80 Bpm A#.wav

音频由用户本地提供，未上传或随发行包再分发。没有对应 WAV 时，请在 SOUND 中改选自己的采样并重新调整区间。应用的通用试听工程 Tone-Check.json 使用内置合成音色，不需要这些 WAV。
