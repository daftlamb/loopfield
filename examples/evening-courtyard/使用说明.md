# Evening Courtyard / 晚庭

三个 Pattern 的 Sitar + Tabla 示例，84 BPM，直拍，A → B → C → A 循环。一轮约 17.14 秒。
以 C 为 Sa，使用 Yaman 音阶色彩和受 Keharwa 启发的八拍伴奏。这是原创融合练习，不是传统 Raga 或 theka 的严格转录。

## 载入

1. 如当前 LOOPFIELD 有未导出的曲子，先保存项目。
2. 点击 LOOPFIELD「打开」，选择 Evening-Courtyard.loopfield.json。
3. 已设为 SONG 模式、三个 Pattern 各播一次、整曲循环。总音量 0 是有意设置：LOOPFIELD 只发送 MIDI，避免内置声音叠加。不要把音轨 MUTE。
4. LOOPFIELD 的 MIDI OUT、Sitar 的 MIDI IN、Tabla 的 MIDI IN 都选同一个虚拟 MIDI 端口。两件乐器分别开启声音。
5. 检查以下通道。通道和端口是浏览器本机设置，不随项目 JSON 导入。

| LOOPFIELD 轨道 | MIDI 通道 | 接收声音 |
|---|---|---|
| 1 GE | CH 1 | Tabla 左鼓开音 |
| 2 KE | CH 2 | Tabla 左鼓闷音 |
| 3 TUN | CH 3 | Tabla 右鼓开音 |
| 4 TIN | CH 4 | Tabla 右鼓清脆敲击 |
| 5 NA | CH 5 | Tabla 右鼓边音 |
| 6 TA | CH 6 | Tabla 右鼓短闷音 |
| 7 SITAR | CH 7 | Sitar 旋律 |
| 8 REST | OFF 或 CH 8 | 空轨 |

轨 1 已带左鼓压音 LFO，输出 CH 1 / CC 1，力度约 0–24%，B 段增至 32%。Sitar 保持 CH 7。

## Sitar 建议设置

PLAYING ASSIST ON；Yaman；TONIC / SA = C；AUTO MEEND 80%；ORNAMENT 18%；DRONE 12%。
CHIKARI 25%；TARAF LEVEL 50%；TARAF DECAY 5 秒；JAWARI 42%；DAMP 22%；MASTER 50%。
MEEND 范围保留 ±7。确保 Taraf 随 Yaman 预设点亮；切换一次预设可重置之前手动改过的共鸣弦。

Tabla 使用默认调音与延音：Bayan 113、Dayan 262，延音均 0.65。先关闭两件乐器的 FX 听清音头、滑音和压力变化；之后再自行加少量混响。

## 三段内容

- A：B3 → D4 → E4，经过 F♯，在 G4 停留后回落；轻鼓花和左鼓压音。
- B：G4 → A4 → B4 → C5，长高音后逐步下降；Tabla 加入较密的应答。
- C：D4 → E4 → F♯4 短句出现三次，最后落到 C4；结尾指击回到 A 的首拍。

所有音符概率 100%，没有随机连击。力度差、留白和长短 Gate 已写在音序中；接收端演奏辅助会继续带来微小差异。

## 预听和验证

Evening-Courtyard-preview.wav 使用当前 sitar-study 和 tabla-study 发声代码离线渲染，采用上面的参数，干声立体声，一轮后留 2 秒尾音。是独立预听文件；LOOPFIELD 的内置 WAV 导出不会自动录回外部网页乐器。

compose.mjs 可重新生成项目，render-preview.mjs 可重新渲染预听；在此目录运行 node compose.mjs / node render-preview.mjs。
