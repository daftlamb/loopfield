# LOOPFIELD

本地浏览器合成器原型。参考用户提供的视频中的低彩度字符界面与参数矩阵，独立实现音频和界面。

## 启动

在本目录运行 `node server.mjs`，打开 http://127.0.0.1:4186 。也可双击 `start.cmd`。

## 操作

- ▶ 或空格：播放 / 停止。首次点击启动浏览器音频。
- 1–8 或音轨按钮：切换音轨。8 轨同时发声；MUTE 静音，SOLO 独奏。
- 格子点按：开关音符；右键只选择。下方编辑选中步的音高、力度、触发概率；↑↓ 调半音。
- NOTE / VEL / CHANCE 切换格子显示的参数。格子均按行从左到右播放。
- 初始 A–D 四份独立乐段，支持新建空白或复制，最多 16 个（A–P）。Pattern 播放中选择其他乐段，会在当前 32 步结束后切换。
- 编排面板可选择 PATTERN / SONG。Song 最多 32 段，每段重复 1–8 次，支持上下排序、删除与整曲循环。播放中锁定编排；停止后修改。非循环播放会保留 FX 尾音后停止。
- 手机音序区固定在一屏：每页 16 步，01–16 / 17–32 按钮切换；下方固定音高、力度、概率、连击。长按格子后上下拖动调当前参数；随机、清空、撤销、八度和调式位于「工具」中。
- 随机、清空等操作可以撤销。保存项目为 JSON；打开 JSON 会载入项目，可撤销恢复先前项目。
- 自动保存到当前浏览器的 localStorage。需要跨浏览器或备份时请下载项目 JSON。
- WAV 可选择当前 Pattern 或整首 Song（按编排播放一遍，不无限循环），44.1kHz 立体声并保留 FX 尾音；概率音符每次渲染结果可能不同。较长的整曲离线渲染会占用更多内存。
- ASCII / PIXEL 使用实际输出频谱，同一音频分析输入可继续扩展视觉场景。

## 验证

`npm test` 验证节拍、项目迁移、Pattern 独立性、Song 重复与边界切换。`/song-test.html` 验证整曲 WAV 时长和实际音频输出。打开 `/audio-test.html` 点击按钮，离线验证 8 种初始音色、WAV 编码和静音路由。

无第三方前端依赖，无云端服务。不保证后台标签页在浏览器省电 / 冻结时持续运行。

## 总线 FX

声音区下方提供 Delay、Reverb、Chorus、压缩和降比特。点击效果名称旁的圆点开关；设置跟随项目保存，老项目默认全部关闭。处理顺序为降比特 → 合唱 → 延迟 → 混响 → 压缩，总音量和最终保护限幅位于其后。降比特使用幅度量化，DRIVE 控制量化前增益；不包含采样率降低。WAV 导出使用同一效果链，并按反馈与混响长度延长尾音。
