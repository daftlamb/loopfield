# LOOPFIELD

## Loopfield Pocket / TRIMUI Brick

Windows 上开发的 ARM64 原生掌机版，1024×768、SDL2 / ALSA。八轨音序、WAV / Slice、限定随机游走、条件触发、Mixer、Punch-in 和 Pluck / Bell / Marimba。

- [掌机说明与构建](handheld/README.md)
- [图形速查表：按键与现场操作](handheld/docs/cheat-sheet-01.png) · [制作与演化](handheld/docs/cheat-sheet-02.png)
- [两页 PDF 下载](handheld/docs/Loopfield-Brick-Cheat-Sheet.pdf) · [可编辑 SVG 与 HTML](handheld/docs/)
- [下载 TRIMUI 安装包](https://github.com/daftlamb/loopfield/releases/tag/pocket-v0.1.0)

掌机版源码与网页版分开，原始项目 JSON 可互相读取；掌机专有声音与调制扩展暂不由网页版播放。用户提供的第三方钢琴采样不随仓库分发。


本地浏览器合成器原型。参考用户提供的视频中的低彩度字符界面与参数矩阵，独立实现音频和界面。

## 启动

在本目录运行 `node server.mjs`，打开 http://127.0.0.1:4186 。也可双击 `start.cmd`。

## 操作

- ▶ 或空格：播放 / 停止。首次点击启动浏览器音频。
- 1–8 或音轨按钮：切换音轨。8 轨同时发声；MUTE 静音，SOLO 独奏。
- 格子点按：开关音符；右键只选择。下方编辑选中步的音高、力度、触发概率；↑↓ 调半音。
- NOTE / VEL / CHANCE 切换格子显示的参数。格子均按行从左到右播放。
- 初始 A–D 四份独立乐段，支持新建空白或复制，最多 16 个（A–P）。Pattern 播放中选择其他乐段，会在当前 32 步结束后切换。
- 编排面板可选择 PATTERN / SONG。Song 最多 32 段，每段重复 1–8 次，支持上下排序、删除与整曲循环。播放中锁定编排；停止后修改。非循环播放会保留 FX 尾音后停止。
- 手机音序区固定在一屏：每页 16 步，01–16 / 17–32 按钮切换；下方固定音高、力度、概率、连击。长按格子后上下拖动调当前参数；随机、清空、撤销、八度和调式位于「工具」中。
- 随机、清空等操作可以撤销。保存项目为 JSON；打开 JSON 会载入项目，可撤销恢复先前项目。
- 自动保存到当前浏览器的 localStorage。需要跨浏览器或备份时请下载项目 JSON。
- WAV 可选择当前 Pattern 或整首 Song（按编排播放一遍，不无限循环），44.1kHz 立体声并保留 FX 尾音；概率音符每次渲染结果可能不同。较长的整曲离线渲染会占用更多内存。
- 画面仅使用 ASCII，默认每 12 秒随机轮播，也可固定场景。角色按统一区域缩放居中，不显示画内字幕。

## 泛音 MIDI 接收

MIDI OUT 可选择「泛音 · 浏览器直连」，再点「打开泛音」，在接收页开启「接收 Loopfield」。默认接收 CH 1，可切换通道与钢鼓 / 手碟音色。直连传送标准 MIDI 音符、力度与关音消息，不需要虚拟 MIDI 驱动；两个页面须在同一站点、同一浏览器中运行。

构建会将相邻 `pan-garden/dist` 打包到 `/pan-garden/`。若两个项目不相邻，先设置 `PAN_GARDEN_DIR` 为该目录的绝对路径，再执行 `npm run build`。本地 `server.mjs` 从构建后的 `dist/pan-garden` 提供接收页。

## 测试

`npm test` 验证节拍、项目迁移、Pattern 独立性、Song 重复与边界切换。`/song-test.html` 验证整曲 WAV 时长和实际音频输出。打开 `/audio-test.html` 点击按钮，离线验证 8 种初始音色、WAV 编码和静音路由。

音频引擎无第三方运行时依赖，无云端服务。不保证后台标签页在浏览器省电 / 冻结时持续运行。

## 总线 FX

声音区下方提供 Delay、Reverb、Chorus、压缩和降比特。点击效果名称旁的圆点开关；设置跟随项目保存，老项目默认全部关闭。处理顺序为降比特 → 合唱 → 延迟 → 混响 → 压缩，总音量和最终保护限幅位于其后。降比特使用幅度量化，DRIVE 控制量化前增益；不包含采样率降低。WAV 导出使用同一效果链，并按反馈与混响长度延长尾音。

## Gate Width

每步可设置 Gate（AUTO 或 5–400%），100% 表示一个当前步的时长，200% 表示两倍。仅改变音符持续时间，不推迟下一步；开启连击时按每个子步时长计算。AUTO 保留原音色包络，旧项目自动使用 AUTO。支持 GATE 格子模式、滚轮、手机长按拖动以及下方滑杆。试听与 WAV 导出同样应用 Gate。

## LFO 与 ARP

在 NOTE / VEL 同一栏点击 LFO / ARP，下方只显示一排预置图标，步进格子保留。点电源开关、数字切换 LFO 1 / 2，点「⋯」展开详细设置，点击面板外空白处关闭（也支持 Esc）。每轨两个 LFO，提供正弦、三角、方波、锯齿、随机阶梯预置，以及 16 点手绘曲线和平滑 / 阶梯连接。可同步 BPM 或使用自由 Hz，连续运行或每个根音重启。每个 LFO 最多映射 6 个参数，起点 / 终点定义范围；反向交换数值即可。LFO 2 对重复目标优先。

音高、音量、声像、滤波、FM 与分轨 FX 支持连续变化；起音、衰减、Gate 在触发时取值。FX 需先在对应音轨启用；混响长度、降比特位深与离散开关暂不参与调制。

ARP 把亮起格子作为根音，支持和弦预置 / 自定义半音偏移，上行、下行、往返、随机，1/8–1/64、三连音和 1–3 八度。NORMAL 逐音触发包络，CHIP 保持一条声音连续变调。Gate 控制整段时长，Ratchet 重启琶音，下一颗有效根音接替上一段；鼓与噪声不启用 ARP。若只听到一个音，可延长 Gate 或提高 ARP 速度。

设置随 Pattern 保存、复制、撤销和 JSON 导入导出，旧项目默认关闭。WAV 使用相同调制和琶音调度。`/mod-test.html` 验证实际 Web Audio 调制、两种 ARP、新根音截断与 Song WAV。

界面通用图标使用 Pixelarticons 2.4.1（MIT），构建时从 npm 包提取所需 SVG 到本地 `icons.js`，无需在线加载。专用 LFO 波形保留像素绘制；全部滑杆使用细轨道与正方形句柄。许可证随构建输出。

ASCII 动画精修源工程见 `art/`：小鸟、摇摆猫、雨景均通过 ASCII Motion 导入检查并导出。统一 64×32 网格，48 帧 / 四拍循环，默认轮播这三组；原场景仍可手动选择。`npm run build` 从源工程生成轻量字符数据。

## 音符预览与 MIDI 输出

调整单步音高时自动试听，支持滚轮、音高菜单、上下方向键和手机长按拖动；连续修改会替换上一声预览，不中断音序播放。

在「音色 → MIDI OUT」点击连接，允许浏览器访问 MIDI，选择输出设备。八轨分别设置 OFF 或 CH 1–16，通道设置保存在当前浏览器。输出跟随静音、Solo、概率、Pattern 和 Song，包含音符、力度、Gate、连击及琶音。CHIP 琶音输出为快速音符；本机音色、FX 和连续 LFO 不转换为外部控制消息。仅听外部设备时可将本机总音量调为零。

停止、切换设备或通道会释放已发送的音符；「关音」立即清除待发送消息并释放使用中的通道。DAW 需选择对应的 MIDI 输入或自行配置虚拟 MIDI 端口。功能需要支持 Web MIDI 的浏览器；不支持时界面会提示。每次打开页面需主动连接设备，不申请 SysEx 权限。

`midi.test.mjs` 验证事件时序、通道与关音；`/preview-midi-test.html` 验证实际 Web Audio 预览音高及 MIDI 消息。外部设备声音仍需接入硬件实测。
